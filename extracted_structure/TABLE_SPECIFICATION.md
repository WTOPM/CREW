## Инструкции для ИИ по воссозданию

### Шаг 1: Создание страницы
```python
from reportlab.lib.pagesizes import A4
from reportlab.pdfgen import canvas

c = canvas.Canvas("crew_list.pdf", pagesize=A4)
width, height = A4  # 595.22 x 842.0 points
```

### Шаг 2: Рисование вертикальных линий
```python
vertical_lines = [79.44, 98.88, 99.60, 253.68, 254.40, 306.24, 306.96, 
                  355.20, 355.92, 399.84, 400.56, 491.28, 492.00, 562.56]

for x in vertical_lines:
    c.line(x, 82.20, x, 623.16)  # От верха до низа таблицы
```
