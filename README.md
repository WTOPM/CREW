# CREW Documents

Настольное приложение для судовых документов: рейс, списки экипажа и пассажиров, PDF-формы для IMO и портовых властей.  
**Версия 0.75** · Windows portable · локальное хранение данных

---

## Release — запуск

1. Откройте **[Releases](https://github.com/WTOPM/CREW/releases)** и скачайте **`CREW-Documents.exe`** (v0.75).
2. Положите файл в любую папку (рабочий стол, флешка, сетевой диск).
3. Запустите двойным щелчком — **установка не нужна**.

При первом запуске рядом с exe создаётся папка **`data`** с пустой базой. Все списки, настройки и сканы хранятся в `data`, а не внутри exe.

**Обновление:** замените только `CREW-Documents.exe`. Папку `data` не удаляйте и не перезаписывайте.

## Как работает программа

| Раздел | Назначение |
|--------|------------|
| **Home** | Текущий рейс (порты, даты), списки crew / passenger (Приход / Уход), архив |
| **Documents** | Генерация и печать PDF из верхнего меню — crew list, passenger list, port of call, ship stores, crew effects, NIL list, ship money, cash advance и др. |
| **Settings** | Печать и подпись судна, порты, ранги, национальности, пакеты документов по порту |
| **Save to folder** | Сохранение PDF в выбранную папку (клик 📁 — добавить; **удержание** 📁 — открыть папку в проводнике) |

**Списки Приход / Уход** — при статусе *Linked* изменения на Приходе попадают в оба списка. Если списки разошлись, Уход только для печати при выходе; синхронизация — **FROM ARRIVAL** / **INTO ARRIVAL**.

**Несколько ПК, одна база** — положите `data` на сетевой диск и создайте **`data-path.txt`** рядом с exe (образец в комплекте релиза). В первой строке — путь к общей папке.

## Где лежат данные

```
CREW-Documents.exe
data/
  crew-data.json      ← все данные приложения
  documents/          ← сканы паспортов / книжек (по желанию)
  assets/             ← печать и подпись судна (по желанию)
data-path.txt         ← необязательно: путь к общей папке data
```

Exe **не содержит** готовых списков экипажа, портов и т.п. — старт с пустой базы или скопируйте папку `data` с другого компьютера.
