# Crew Documents

Приложение для управления данными судна и экипажа. Локальное хранение, portable EXE для Windows.

## Запуск в браузере (разработка)

```bash
npm start
```

Откройте http://localhost:4200

## Запуск как desktop-приложение (разработка)

```bash
npm run electron:dev
```

## Сборка portable EXE (без данных)

```bash
npm run electron:build
```

Готовый файл: `CREW-App/CREW-Documents.exe`

**Сборка не содержит данных судна, экипажа и портов** — только шаблоны PDF и логотип. При первом запуске создаётся пустой `data/crew-data.json` рядом с EXE.

### Подключение данных с другого компьютера

**Вариант A — скопировать папку `data/`**  
С другого ПК скопируйте всю папку `data/` (рядом с EXE) и положите её рядом с новым `CREW-Documents.exe`. Внутри должны быть `crew-data.json`, при необходимости `documents/` и `assets/`.

**Вариант B — общая сетевая папка (несколько ПК)**  
1. Положите `data/` на сетевой диск (например `\\SERVER\share\CREW-data`).  
2. Рядом с EXE создайте файл `data-path.txt` (образец: `data-path.txt.example` в папке сборки).  
3. В первой строке укажите путь к общей папке — все компьютеры будут читать и писать одни и те же данные.

**Вариант C — переменная окружения**  
`CREW_DATA_DIR=D:\CREW-data` — папка с `crew-data.json`.

## Функции

- **Главная** — данные судна (вкладка Input), текущий экипаж, архив
- **Crew Arr.** — форма IMO CREW LIST (FAL Form 5), генерация PDF
- **Импорт Excel** — загрузка из `DOCUMENT.xlsx`
- **Экспорт/импорт JSON** — резервное копирование данных
